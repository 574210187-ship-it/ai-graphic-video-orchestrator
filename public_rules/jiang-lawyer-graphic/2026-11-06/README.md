## 使用

1. 依据对标页类型选择一份 MD：01 为蓝色新闻播报文字风格，02 为中国公检法实拍强虚化背景，`单页姜律师` 用于对标页出现律师形象的单页画面；多页规则按文字页数使用。
2. 在新的 ChatGPT 对话中，先附上所选 MD 和对标图片；01 同时附上本轮指定的单张纯蓝背景图，`单页姜律师` 同时附上本轮指定的姜律师形象图。先要求完整阅读 MD 和全部素材，再按 MD 生图。
3. 本轮正文默认逐字使用对标完整页；只有执行指令明确提供“用户授权替换清单”时，才按清单替换完整片段。清单外文字、数字、标点、事实和法律结论均保持原样。
4. 完成图片后，如需制作单页视频，下载并解压 `【图文】姜律师Video单页.zip`，先阅读其中的 `执行说明.txt`，再按其中步骤执行。

## 新窗口可直接使用的指令

```text
请完整阅读我附上的 MD、对标图片及本轮素材，全部看完后再开始。严格按 MD 用 Imagegen 生成本轮所需图片；正文默认逐字使用对标完整页，只有我明确提供“用户授权替换清单”时才替换清单中的完整片段。不要自行增删、概括或改写文字。
```
