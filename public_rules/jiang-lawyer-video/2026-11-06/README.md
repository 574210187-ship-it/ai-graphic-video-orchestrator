# 姜律师图文视频规则包

这是一套可直接交给 ChatGPT 视频执行窗口的正式分发包。本目录只包含当前两份视频规则 ZIP 和一个可选的蓝色背景视频素材包；不包含任何客户图片、对标视频、音频或已生成成片。

## 下载

在本目录中点击所需 ZIP，进入文件页后选择 **Download raw file**。也可使用下列相对链接：

| 文件 | 用途 | 是否必须下载 |
| --- | --- | --- |
| [【图文】姜律师Video单页.zip](packages/【图文】姜律师Video单页.zip) | 单页图文视频：背景图 + 透明文字图；可选成品图。 | 单页任务下载此包 |
| [【图文】姜律师Video多页.zip](packages/【图文】姜律师Video多页.zip) | 多页图文视频：共用背景 + `text_01.png`、`text_02.png` 等多张透明文字图。 | 多页任务下载此包 |
| [jiang01蓝色视频背景.zip](optional-assets/jiang01蓝色视频背景.zip) | 三条静音蓝色视频背景素材。 | 仅在需要该蓝色视频背景时下载；常规任务并不需要 |

## 在 ChatGPT 中使用

不要改名、不要解压 ZIP。把所选规则 ZIP 和本轮素材一同发到视频执行窗口，再只发送这一句：

```text
严格按照 ZIP 内 TXT 执行。
```

### 单页包的本轮素材

- `background.png`：不透明背景图；
- `text.png`：与背景同画布、带 Alpha 的透明文字层；
- `final.png`：可选成品图。存在时，文字动画完成后会平滑过渡到它；
- 可选对标视频、指定视频或独立音频：规则会按 ZIP 内既定优先级取第一条可读音轨。

### 多页包的本轮素材

- `background.png` 或 `background_video.mp4`：二选一的共用背景；
- `text_01.png`、`text_02.png`……：按页顺序的透明文字层；
- 可选对标视频、指定视频或独立音频：有对标视频时按其真实翻页时间映射页面切换。

两份规则包均不生成 HTML、不要求累计记忆文档；完成后只交付 `MP4.zip`，其中只含 `final_animation.mp4`。动画和成片均不包含光效。

## 完整性

下载后可按同目录 [SHA256SUMS.txt](SHA256SUMS.txt) 核验。以本目录中的 ZIP 文件与哈希为准。
