# 姜律师图文候选行口径

## 长期默认口径

程序现按两级或条件领取：

1. 优先级一：`二次分类型=图文`；
2. 优先级二：`类型=图文`，不限制`二次分类型`为空或其他值。

两个条件任意满足一个即命中。两者都满足时只领取一次，归入优先级一。先处理优先级一，再处理优先级二。

命中分类后还必须同时满足：

1. 按配置的来源优先字段查找后，恰有1个可用附件；
2. `成品`和`已发布`两列都没有视频附件；
3. 不以`状态`字段代替上述两列实物判定；
4. 真实下载后按文件魔数和媒体流判断类型，不信任扩展名。

## 2026-10-29一次性宽口径

当时用户明确授权把`类型=图文`且`二次分类型`为空的记录也纳入该批。实时初筛得到69行：

- 2行：`二次分类型=图文`；
- 67行：`类型=图文`且`二次分类型`为空。

这69行均满足：来源附件唯一，且`成品`、`已发布`两列均无视频。随后下载发现`reczz28OnI1YUWOE`虽命名为MP4，实际是纯MP3音频，因此可视候选为68行。

后续真正启动全量执行时，表格又发生了外部完成和实时状态变化，固定快照为64行。`69 → 68 → 64`是同一口径在不同时点的“初筛、真媒体验证、开工冻结”数字，不是三次随意换规则。

## 复用不改变行数

不同record_id的来源SHA-256完全相同时，可以在已验收的前提下复用成品，但每个目标行仍要独立上传、写回和实时回读。复用只减少网页生成，不减少待办记录数。

## 规则升级说明

2026-10-29的67行空二次分类原本是当批授权。用户于2026-11-01明确将它升级为长期规则，并进一步允许`类型=图文`且二次分类为其他值的记录纳入优先级二。
